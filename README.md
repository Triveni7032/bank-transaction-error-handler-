# Bank Transaction Error Handler

A beginner-friendly Python banking application that demonstrates
Exception Handling and safe error management.

## Features

- Check account balance
- Deposit money
- Withdraw money
- View transaction history
- Handle invalid user input
- Handle insufficient balance
- Handle missing files
- Store transactions in a text file

## Technologies Used

- Python
- Exception Handling
- try
- except
- else
- finally
- File Handling
- Functions
- Loops
- Conditional Statements
